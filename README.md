# LH Challenge Questions
Question solutions for the practical challenge stage of the Indicium Lighthouse selection program.
<br>
<br>

## Structure
- All questions have been answered in the respective folders with their names (```question1/```...).
- The dashboard report and implementation is contained within the ```dashboard/``` directory.
<br>
<br>

## How to run
- Clone the repository:
```bash
git clone https://github.com/beaalmeidas/lh-challenge-questions.git
```

- Install the dependencies:
```bash
pip install -r requirements.txt
```

- Make sure to have docker installed and running for questions 1-3, as they're implemented in SQL and utilize a database running in docker.

- Implement the `.env-example` file with the local variables of your docker database.

- Some paths to files may need to be adjusted, as some notebooks were implemented in Colab, with diferent project structure from the one here.
